# ИС «МосТранспорт»

Информационная система навигации по маршрутам общественного транспорта Москвы.
Учебный проект МАИ (проектный практикум, 2025–2026).

## О проекте

Клиент-серверное веб-приложение для планирования поездок по городу с использованием
общественного транспорта. Построение маршрута осуществляется по алгоритму Дейкстры
на взвешенном мультиграфе транспортной сети (библиотека NetworkX).

Соответствует техническому заданию, выполненному по ГОСТ Р 59793-2021. Все модули
структурированы согласно разделу 4.1.1 ТЗ.

## Возможности

- Построение оптимального маршрута между двумя точками с использованием метро и
  наземного общественного транспорта
- Учёт пересадок и пешеходных подходов (радиус до 800 м)
- Геокодирование адресов через Nominatim (OpenStreetMap)
- Интерактивная карта на Leaflet.js
- REST API с автоматической документацией (Swagger UI)
- Адаптеры для data.mos.ru, API Мосгортранса и OpenStreetMap

## Установка и запуск

### 1. Подготовка окружения

```bash
git clone <repository>
cd mostransport
python3.11 -m venv venv
source venv/bin/activate        # Linux/macOS
# или: venv\Scripts\activate    # Windows
pip install -r requirements.txt
```

### 2. Конфигурация

```bash
cp .env.example .env
# Откройте .env и заполните ключи API
```

Ключ для data.mos.ru получается на https://data.mos.ru (раздел «Разработчикам»,
самостоятельная регистрация).

### 3. Инициализация и загрузка данных

```bash
# Создать схему БД
python manage.py init_db

# Вариант A: загрузить учебный датасет (центр Москвы, 30 станций)
python manage.py load_mock

# Вариант B: загрузить реальные данные из data.mos.ru и OSM
python manage.py update_data
```

### 4. Запуск

```bash
uvicorn app.main:app --reload
```

Приложение откроется на http://localhost:8000
Swagger UI: http://localhost:8000/docs

## API

### Построить маршрут

```
GET /api/v1/route?from_lat=55.7356&from_lon=37.5937&to_lat=55.7758&to_lon=37.6558
```

### Геокодировать адрес

```
GET /api/v1/geocode?q=Красная площадь
```

### Информация об остановке

```
GET /api/v1/stops/{id}
GET /api/v1/stops/nearby?lat=55.7558&lon=37.6176&radius_m=500
```

### Состояние системы

```
GET /api/v1/health
```

Полная спецификация — в Swagger UI на `/docs` или в ТЗ (Приложение Г).

## Разработка и расширение

В коде размещены комментарии `TODO: Здесь планируется...`, указывающие на планируемые
точки расширения функциональности. Они соответствуют перспективам развития из ТЗ
(п. 4.1.6) и не должны быть оставлены в продакшен-сборке.

Основные точки расширения:
- Загрузка маршрутов из API Мосгортранса (`app/data/mosgortrans.py`)
- Поддержка расписаний (`app/db/repository.py`, `app/routing/graph.py`)
- Фоновая задача обновления данных (`app/main.py`)
- Словарь топонимов и морфология (`app/geocoder/`)
- LRU-кэш маршрутов (`app/routing/pathfinder.py`)
- Отображение альтернативных маршрутов (`static/js/app.js`)
- Миграция на PostgreSQL + PostGIS (`app/db/connection.py`)
